# Google Sans

`font.ttf` is Google Sans, the variable font this extension loads at runtime (`font-family: "Google Sans"`, see `src/views/App.tsx`) and bundles into `dist/` at build time (see `build.js`).

The font belongs to Google and is published as open source. See [fonts.google.com/specimen/Google+Sans/license](https://fonts.google.com/specimen/Google+Sans/license) for details.
